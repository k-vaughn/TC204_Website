# Ontology Registry

| i72 | <https://w3id.org/citydata/21972/v1/> | <https://isotc204.org/ontology-i72-v1/latest/> | Upper level ontology for smart city indicators (ISO 21972) |
| org | <http://www.w3.org/ns/org#> | <https://isotc204.org/ontology-import-org/latest/> | The W3C Organization Ontology |
| prov | <http://www.w3.org/ns/prov#> | <https://isotc204.org/ontology-import-prov/latest/> | The W3C Provenance Ontology |
| schema | <https://schema.org/> | <https://isotc204.org/ontology-import-schema/latest/> | The Schema.org ontology |
| time | <http://www.w3.org/2006/time#> | <https://isotc204.org/ontology-import-time/latest/> | The W3C Time Ontology |

| cdm2 | <https://w3id.org/citydata/part2/v1/> | <https://isotc204.org/ontology-cdm-p2-v1/latest/> | City Data Model - Part 2: City level concepts |
| cdm3 | <https://w3id.org/citydata/part3/v1/> | <https://isotc204.org/ontology-cdm-p3-v1/latest/> | City Data Model - Part 3: Service level concepts - Transport |

| itsTransportNetwork | <https://w3id.org/itsdata/transport-network/v1/> | <https://isotc204.org/ontology-its-transport-network-v1/latest/> | Ontology that imports the transport-network pattern modules for transport-network, road, rail, pedestrian, micromobility, public transport, travel corridor, and alerts. |
| itsVehicle | <https://w3id.org/itsdata/vehicle/v1/> | <https://isotc204.org/ontology-its-vehicle-v1/latest/> | Vehicle ontology |
